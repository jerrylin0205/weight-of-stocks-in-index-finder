# 手動持股資料（manual source）

放在這個資料夾的 `<TICKER>.csv` 會被 `source: manual` 的 ETF 讀取。
用途：抓不到的 ETF（多數台股投信），或你想用權威來源（TEJ、發行商月報、Bloomberg 匯出）覆蓋自動抓的資料。

## 格式

CSV，第一列是欄位名（大小寫、中英文皆可）：

| 欄位 | 別名 | 必填 | 說明 |
|---|---|---|---|
| `ticker` | `code` / `代碼` / `商品代碼` | ✓ | 股票代號。台股填 4 碼數字 |
| `weight` | `weight (%)` / `權重` / `比重` | ✓ | 佔指數/ETF 權重，單位 %（`7.06` = 7.06%） |
| `name` | `名稱` / `商品名稱` |  | 顯示用 |
| `as_of` |  |  | 資料日期，整份檔案共用一個（例：`2026-08-31`） |

- 以 `#` 開頭的行會被忽略。
- 全部 `weight` 加總應接近 100（系統會在 fetch 時檢查，偏離太多會顯示 WARN）。

## 範例

```csv
ticker,name,weight,as_of
2330,台積電,57.08,2026-09-09
2454,聯發科,6.45,2026-09-09
2317,鴻海,2.92,2026-09-09
```

存成對應檔名（例如 `00878.csv`）後執行：

```bash
uv run indexfinder fetch --only 00878
```
